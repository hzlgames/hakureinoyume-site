# 直播共享字幕验证记录（2026-10-14）

实现位于审核分支 `codex/live-subtitles`，工作目录 `/home/ubuntu/hakureinoyume-live-subtitles`。生产 main、生产数据库 schema、Caddy 和 systemd 服务未更改。测试数据库与站内测试会话独立；使用服务器已有的两个实际用户及其加密 ZJU 绑定，不修改原用户资料、密码或原有会话。

## 智云接口实测

目标为课程广场《证据法学》，`courseId=87601`、`subId=2034357`、之江曾宪梓楼-203。两名已有用户均能正常读取该课节及播放地址。

直播期间的 `search-trans-result?sub_id=2034357&format=json` 对两个用户均返回 HTTP 200，但业务 code 为 `10002`、提示“未查询到语音数据”、`list=[]`。不能把 HTTP 200 当作已有直播字幕。

下课期间目录状态从 `1` 改为 `3`，回放尚未就绪；实现针对这一状态保留已授权用户的字幕读取权限，并让后台停止识别。稍后状态变为 `6`，回放生成，字幕接口变为 code `0`、`list` 一条。这证明本次智云原生字幕可用于课后转录，尚未证明可用于实时直播。

教师/教室 HLS 实际包含 H.264 视频及 AAC 单声道音频，采样率 32000 Hz。媒体列表是六个约两秒的 TS 分片，没有 `PROGRAM-DATE-TIME`。课件与学生画面探测超时；实现只处理上游明确标记的教室音源，未知画面不会兜底上传。

## 真实直播识别

付费探测送入该课节 540 秒教室音频，运行 548.26 秒，收到 1298 次服务响应，正常完成九次一分钟会话。返回包含真实中文讲授内容，证明该服务器、密钥和 2.0 流式链路可用。

随后共享后台使用两个已有用户同时加入，返回相同任务 ID，generation 为 1；处理 88 个教室分片、约 176.16 秒音频。这段已接近下课，音频接近静音，没有确定分句，不将其描述为完整的字幕质量验证。目录转为下课状态后检查了后台正常收尾与课后访问。

## 同课节回放的长时间 ASR 与恢复

直播已下课，因此长时间测试使用同一课节刚生成的教室回放，从回放第 70 分钟取音频。仍发送到真实火山引擎，使用正式的共享任务、租约、音频预算、字幕分句写入和读取函数。测试在另一独立数据库执行；测试音源注入入口不对网站 API 开放。

两项独立后台进程竞争同一任务，任意采样点最多一个有效识别任务。到五分钟时对活动进程发送 SIGKILL；另一个进程接管，generation 从 1 变为 2。此前已确定的 21 句仍保存在数据库中，随后继续新增字幕。退出一名用户的观看订阅后，另一个用户的识别继续，历史访问记录不被删除。

最终处理音频 1200 秒，运行约 1242.26 秒（含启动和租约接管），保存 103 句确定字幕，覆盖 20 个有确定字幕的识别会话。达到测试配置的二十分钟上限后，状态变为 `limited`，有效后台任务数归零。它验证真实 ASR 与后台持续运行和恢复，不替代整节课直播、签名过期或所有课程音源的验证。

真实浏览器使用两个已有用户的独立站内测试会话，从实际 API 读取同一任务；23 句确定字幕出现后刷新页面，课程选择、字幕开关和此前的第一句均恢复。此项使用真实数据库字幕，没有字幕响应 fixture。

## 自动化与浏览器

19 项针对性检查通过：原直播/回放回归、纯协议、PCM 边界、分片时间映射、403 媒体权限拒绝、仅教室音源、真实本地 WebSocket、FFmpeg 取消清理、数据库任务竞争、租约接管、旧进程写入拒绝、分句修订去重、临时文本时间戳、解绑只撤销个人授权而保留共享字幕，以及七天过期级联清理。

两小时模拟 PCM 通过 120 次 ASR 会话轮换，音频总量和 offset 连续；没有残留的会话结果队列或不断增长的 WebSocket 集合。这是加速模拟，不是两小时真实云端识别。

浏览器 fixture 检查桌面 1280px 和移动端 390px、明暗主题、HLS 分片同步、临时字幕、暂停、F5、单个 TextTrack、原生视频全屏、关闭字幕及页面错误。fixture 画面和字幕明确标记为模拟；不把这些截图作为真实直播准确率证据。

lint、TypeScript 和 Next.js webpack 构建通过。部署模板仅保存于分支，未安装或启用生产后台。
