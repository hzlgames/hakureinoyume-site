# 0010 以持久分段任务共享回放字幕

## Status

Accepted

## Context

回放字幕需提供学校已有字幕与火山识别两种来源；后者需多人复用、避免整课媒体积压，并能中途停止费用。标准版文档只提供 submit/query，不能承诺撤销云端已接受的录音。

## Decision

按课程和实际课节长期保存 SRT/TXT，用户请求独立关联共享缓存；学校字幕导出保持原状。音频最多一分钟一段，45–60 秒优先在低能量停顿切分，重叠 1.5 秒并传递前文上下文；重叠计入预算，边界重复文本合并去除，串行提交标准识别，内存 WAV 不落盘。预留预算并记录请求 ID 后提交，重启查询原 ID；中止最后一个请求撤销租约并终止本地处理，不提交后续段。当前已进入提交边界的一段仍可能收费。直播与回放使用同一并发、预算事务锁；指定账户的免配额使用独立字段和用量计数，不依据显示名或客户端参数动态授权。

## Consequences

恢复和共享避免重复识别；最多一段的提交边界仍存在不可撤销费用。停顿切分、重叠和上下文降低截断风险，但短段边界仍可能影响语境；没有人工字错率对照，字幕质量需抽查。文本长期保存依赖数据库备份和容量管理。中止个人请求不能取消其他人的共享任务；下载仍须通过每个用户的学校权限验证。
