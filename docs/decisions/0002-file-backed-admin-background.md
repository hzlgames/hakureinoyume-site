# 0002 使用文件系统保存后台背景图

## Status

Accepted

## Context

项目已经有 PostgreSQL 账号库，但当前后台背景图只有一个当前版本，访问路径需要能被公开页面直接引用。背景图本身是二进制静态资源，不适合直接放入认证数据库。

## Decision

将后台上传并裁切后的 webp 写入 `public/backgrounds/admin-background.webp`。读取时根据文件 mtime 生成查询参数版本，删除时移除该文件并回到预设背景。写入和删除需要 `admin` 角色，并记录管理员审计日志。

## Consequences

- 实现简单，适合单站点和单背景图需求。
- 背景图文件跟随服务器本地磁盘，不适合多实例无共享存储部署。
- 写权限、备份和发布流程需要避免误删运行时生成文件。
- 背景变更的行为记录进入 `AdminAuditLog`，但图片文件仍在服务器本地磁盘。
- 如果未来需要多背景历史、审核或跨实例部署，应迁移到数据库加对象存储。
